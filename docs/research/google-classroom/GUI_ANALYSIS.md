# Classroom GUI

创建与最近更新 2026-11-28 · MicroHub 审计基线 `32150ab4bdd46327f52e42e2431dfaa0b5198b95`

S34 官方教师图解、S35 历史第三方导航图与 [演示观察](evidence/README.md) 支持下列结构。图解及演示的视觉表现按来源标明。当前登录后界面未进行像素取样。

| 层级       | 证据中的设计                                                   | 交互价值与 MicroHub 对应                     |
| ---------- | -------------------------------------------------------------- | -------------------------------------------- |
| 桌面 Shell | 菜单、应用／账户区，侧栏可收起；页内班级标签分开               | 全局和对象导航语义分层，支持保留当前工作范围 |
| 首页       | 类别或角色视图、班级卡片网格、要做事项和行内操作               | 重复入口有助跨班级工作，单学会改为个人队列   |
| Stream     | 班级头部、公告撰写入口、消息流与近期提示                       | 组合快速读写；MicroHub 优先公告与可执行任务  |
| Classwork  | Create、主题索引或标签和垂直条目；展开文本与附件               | 列表便于扫读，将按对象才出现的操作延后       |
| 编辑器     | 广域内容编辑，旁边放对象、评分、截止；页头主动作与更多发布方式 | 表单先说明再局部选择，窄屏按工作顺序         |
| 学生详情   | 作业说明／附件与个人工作区有清楚的视觉分组，私人评论独立       | 保留分组及明确命令；手机顺序先状态再行动     |
| 批改       | 名册／状态汇总、选中提交和文件、评论及退回                     | 适合双栏，窄屏支持携带筛选返回               |
| 成绩表     | 人员×任务矩阵、点数／状态、工具菜单                            | 较适合密集比较，注意横宽及键盘上下文         |

## 视觉

官方图解可定性观察到浅背景、不同层次表面、彩色班级主体、常见线条图标和文字菜单。板块通常用排列、留白和细分隔区分。图解版本和角度不同，无证据支持固定的 Classroom 主品牌色 hex、字体精确字号、字重、断点、像素间距、阴影或全局 Material Token。文档中的 CSS 数值属于 MicroHub 目标。Material 的操作分层、状态反馈和表面语义是比较维度，不能凭外观归认明确版本。当前产品暗色、平板网格和手机原生浮动按钮的测量均待实测。
