创建与最近更新 2026-11-28 · MicroHub 审计基线 `32150ab4bdd46327f52e42e2431dfaa0b5198b95`

S28（OFFICIAL）描述电脑 Screen Reader 的 banner／navigation／main、加入班级、切换账户、查看成绩或会议跳转。官方提到移动 Screen Reader 支持及推荐浏览器；S29 提及可调学生无障碍功能。演示本身可读取按钮与标题。演示的可读语义只能说明演示页。

实际 Classroom 的键盘完整路径、焦点环、Dialog 焦点回归、字号放大、200% 缩放、320 CSS px 重排、字号和色彩对比、目标物理尺寸、拖拽替代办法、支持 Reduced Motion、TalkBack／VoiceOver 口播及排序均为 UNVERIFIED。使用 WCAG 2.2（S37）作为 MicroHub 工程标准，不直接宣称 Classroom 符合 AA。需要合成学员、教师与机构测试账户；重复导航、可-不可见的菜单、状态播报及错误恢复纳入录像或操作记录。
