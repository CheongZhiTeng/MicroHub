# 易用性判断与迁移

创建与最近更新 2026-11-28 · MicroHub 审计基线 `32150ab4bdd46327f52e42e2431dfaa0b5198b95`

| 问题          | 证据与判断                                                                  | MicroHub 启发                         |
| ------------- | --------------------------------------------------------------------------- | ------------------------------------- |
| 01 初学者定位 | 班级卡、Stream、近期作业形成可识别起点（S05、S35）                          | 登录后直接给学会角色起点              |
| 02 功能密度   | 全局、班级、行菜单分层（S05、S06）                                          | 分开菜单和任务对象                    |
| 03 当前行动   | Due soon、To-do、Your work、To review（S05、S15、S40）                      | 首页显示应办任务和即时签到            |
| 04 低频操作   | 班级归档及行管理在菜单（S04、S06）                                          | 编辑及危险操作按对象与权限显示        |
| 05 内容组织   | Stream、Classwork、People 独立（S05、S06）                                  | 公告和作业各有正入口                  |
| 06 状态       | Assigned、Missing、Done，教师另有待批与退回（S16、S18）                     | 用生命周期、迟交及发布分轴            |
| 07 重复输入   | 帖子复用、教师评论库、Rubric（S14、S17、S20）                               | 优先现有 GradingLibrary，慎重复制受众 |
| 08 跳转       | 作业状态落到名单、批改中切人（S16、S17）                                    | 保留筛选并恢复焦点                    |
| 09 避免误操作 | 提交／撤回确认，文件分享类型，归档前置（S04、S09、S15）                     | 确认说明当前版本和影响                |
| 10 首次引导   | 加入有邮件、链接、代码入口；账户资格分流（S01、S02）                        | 验证邮件后显示下一步与申请状态        |
| 11 角色差异   | 教师有发布、People 管理及 Grades；学生自有工作（S05、S06）                  | 权限能力决定入口和操作                |
| 12 复杂表单   | 作者控制内容、受众、截止、评分、附件（S09、S34）                            | 主字段固定，提交规则按需展开          |
| 13 批量管理   | 学生状态、选择、批量 Return（S16、S40）                                     | 继续遵守逐修订同意与服务器复核        |
| 14 移动操作   | 支持移动交付与查阅，部分配置和协作文档依赖外部应用（S15、S17、S27、S42）    | 全部已有职能建立窄屏等价流程          |
| 15 桌面空间   | 名册、提交、反馈同屏，成绩表矩阵（S16、S34）                                | 放大生产性区域，普通页使用可读宽度    |
| 16 采用       | 任务状态队列、细节主动作、低频菜单、带上下文返回                            | 导航和提交页先落地                    |
| 17 不适合     | 跨班卡片、SIS、全校成绩表、额外 Workspace 产品链                            | 单学会和大课／小组范围固定            |
| 18 产品摩擦   | 作业展开后可能多一步，Stream 有公告和作业混流，重交可意外变迟交（S08、S15） | 私有回执明确后果、队列直达详情        |
| 19 可胜出     | 学会同时有活动签到、受众人数、组交接和保留历史需求                          | 连通活动及签到，任免前预览历史影响    |

以上为证据支持的结构与设计解释。上手时长、点击效率和认知负荷均未做用户实验。
