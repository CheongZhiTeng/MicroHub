# Google Classroom 功能目录

创建与最近更新 2026-11-28 · MicroHub 审计基线 `32150ab4bdd46327f52e42e2431dfaa0b5198b95`

每行以入口、定位和操作顺序说明 UI、主要输入及成功后的状态。角色栏是前置条件，另需有效账号、授权和相应数据。说明来自 [SOURCES](SOURCES.md) 的 **OFFICIAL** 文档，GC-01 的登录边界为 **OBSERVED**，GC-54 与 GC-59 对应演示见 [界面证据](evidence/README.md)。空白、加载、超时、焦点、工作流失败及移动端同等能力缺少逐项实测，均记 **UNVERIFIED**。关键系列的适用异常、平台与取舍见 [产品分析](PRODUCT_ANALYSIS.md)、[流程](USER_FLOWS.md)、[组件](COMPONENT_ANALYSIS.md) 和 [覆盖表](RESEARCH_COVERAGE.md)。
