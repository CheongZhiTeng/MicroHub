# 认证与会籍启动逐屏规范

创建与最近更新 2026-11-28 · MicroHub 审计基线 `32150ab4bdd46327f52e42e2431dfaa0b5198b95`

**Proposed**。本页每个界面全部适用 [状态](../INTERACTION_PATTERNS.md)、[响应式](../RESPONSIVE_DESIGN.md)、[双主题](../DESIGN_SYSTEM.md) 和 [无障碍](../ACCESSIBILITY.md)。使用 auth 440 容器。手机单栏、主键盘动作就近；平板保持居中而允许展开校验文本；桌面保留表单内容并缩短品牌辅助文字。两主题可读，阶段标题、字段错误及验证码读屏连贯。

## SCR-00 入口与启动

- 路由与实现 `/` · `app/index.tsx`。目标角色 所有。
- 目的与当前问题。初始配置与会话错误目前使用普通块。
- 目标布局与主操作。按配置、会话加载、离线、恢复和已认证派发；主动作仅在可重试时显示。
- 组件、次操作和跳转。Loading、Notice、Button 与 SessionProvider。
- 状态、权限及恢复。不跳过恢复会话或把未配置误判为访客。
- 验收。启动无闪屏，错误可重试，注册登录和已认证各到合法入口。
- 设计依据。E01。

## SCR-01 登录

- 路由与实现 `/sign-in` · `app/sign-in.tsx`。目标角色 访客及过期会话。
- 目的与当前问题。上方有多层品牌和偏好；深链接白名单位于路由内。
- 目标布局与主操作。标题→学校邮箱、密码→登录→注册／恢复；语言、主题为辅助。
- 组件、次操作和跳转。Field、PasswordField、Notice；有效 next／id／mode 验证后回目标。
- 状态、权限及恢复。无效邮箱／密码、离线、重复点击不丢合理输入；过期提示可重登。
- 验收。没有任意返回路径，320宽度可使用密码眼、中文长名与键盘输入。
- 设计依据。GC-01。

## SCR-02 注册／邮箱 OTP

- 路由与实现 `/register` · `app/register.tsx`。目标角色 访客、需校验邮箱者。
- 目的与当前问题。创建和校验共用一页；完成验证仍需入会。
- 目标布局与主操作。每步仅一个主动作；标出当前学校邮箱，支持已有验证码／重发／换邮箱。
- 组件、次操作和跳转。AuthSteps、Field、PasswordField；校验成功进入入会 Gate。
- 状态、权限及恢复。过期、频率限制、验证码粘贴、已有账号引导；实际发送失败保留邮箱。
- 验收。OTP 未成功前不可受保护访问；保留现行密码规则与服务端身份校验。
- 设计依据。GC-01、06。

## SCR-03 密码找回、重置

- 路由与实现 `/recover` · `app/recover.tsx`。目标角色 访客、恢复会话。
- 目的与当前问题。三步沿用同路由；退出故障有单独状态。
- 目标布局与主操作。邮箱→校验→新密码；成功给明确登录下一步；恢复会话隐藏工作导航。
- 组件、次操作和跳转。Field、PasswordField、Notice、Button。
- 状态、权限及恢复。安全错误文案、验证码过期、重发、更新成功但登出失败可重试。
- 验收。不暴露是否存在其它账号，恢复会话无法查私有内容，成功回登录。
- 设计依据。GC-03。
