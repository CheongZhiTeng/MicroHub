# 作业与提交逐屏规范

创建与最近更新 2026-11-28 · MicroHub 审计基线 `32150ab4bdd46327f52e42e2431dfaa0b5198b95`

**Proposed**。本页每个界面全部适用 [状态](../INTERACTION_PATTERNS.md)、[响应式](../RESPONSIVE_DESIGN.md)、[双主题](../DESIGN_SYSTEM.md) 和 [无障碍](../ACCESSIBILITY.md)。手机列表与详情逐屏，提交主操作位于安全区；平板在可用容器足够时显示分栏；桌面编辑内容和受众设置并列，批改名单与版本详情并列。双主题语义状态，附件行给文件名和合理权限提示，返回回焦。

## SCR-05 作业列表及待办

- 路由与实现 `/homework` · `app/(tabs)/homework.tsx`。目标角色 学生、授权研教、未来全权限。
- 目的与当前问题。多种筛选、状态和模式组合需清晰。
- 目标布局与主操作。标题与范围→下一步或待批→状态筛选→紧凑列表，管理新建为角色主动作。
- 组件、次操作和跳转。AssignmentList、Choices、Paging；行直达 assignment。
- 状态、权限及恢复。没有作业、未分配、筛选无匹配和错误分开；返回保留筛选。
- 验收。范围权限不变；老师待批、草稿、计划和学生时间状态可区分。
- 设计依据。GC-16、35、49。

## SCR-06 作业详情、个人提交、讨论、评阅、管理

- 路由与实现 `/assignment` · `app/assignment.tsx`。目标角色 学生及有权人员。
- 目的与当前问题。一条 URL 支持课程预览、交付及回执、queue／manage 等模式；分层需明确。
- 目标布局与主操作。学生：状态与截止→说明附件→编辑提交→回执与历史→可发布反馈；管理：范围与工作区→名单、评分、报告和低频管理。
- 组件、次操作和跳转。DraftPreview、StudentWork、Discussion、Grading、Reports、ChangeHistory。
- 状态、权限及恢复。冲突、临期、已关闭、退回修改、附件未就绪、提交历史、发布成绩的既有状态；URL 的 mode 仅影响界面。
- 验收。遏制重复提交；版本与附件和私有反馈绑定；管理无合法权时不显示私有队列；返到正确来源。
- 设计依据。GC-29–38。

## SCR-07 创建和编辑作业

- 路由与实现 `/assignment-editor` · `app/assignment-editor.tsx`。目标角色 授权研教及未来全权限。
- 目的与当前问题。复杂设置、附件与核对同流程，创建与编辑受境况限制。
- 目标布局与主操作。标题、受众及人数、说明截止置前；评分、修订、附件规则按需求折叠；预览后保存、排程或发布。
- 组件、次操作和跳转。AssignmentEditor、Audience、FilePanel、PolicyEditor、HomeworkDraftProvider。
- 状态、权限及恢复。未保存提醒；附件上传失败就地重试；不可编辑的版本字段解释；批次变化重取。
- 验收。收件数一致，两栏或单栏不清表单，保留联合提交规则和旧 RPC 对应。
- 设计依据。GC-17、23–28。

## SCR-08 我的提交

- 路由与实现 `/submissions` · `app/submissions.tsx`。目标角色 有会籍成员。
- 目的与当前问题。复用 AssignmentList，历史与即时待办入口含义可能重叠。
- 目标布局与主操作。作为作业内次级历史保留深链；按已交、已返回可见状态和有效分页。
- 组件、次操作和跳转。AssignmentList submissions、Paging、Receipt 链接。
- 状态、权限及恢复。无可见历史不表示无作业；权限撤销时不可复用旧数据。
- 验收。只显示自己的回执和授权组交付信息，返回不丢筛选。
- 设计依据。GC-32、38。

## 作业详情与批改布局

| 区域     | 手机                                                 | 平板与桌面有足够容器                                         |
| -------- | ---------------------------------------------------- | ------------------------------------------------------------ |
| 学生首屏 | 截止与状态 → 可执行操作，说明、附件与提交随后        | 左说明与附件，右本人工作；DOM 阅读先说明和操作               |
| 交付     | 草稿 → 文件就绪 → 提交确认 → 最新回执 → 独立版本历史 | 使用同一状态顺序；评分已发布内容贴对应版本                   |
| 评阅     | 队列名单 → 单人／版本 → 保存草稿、返回或申请修订     | 左名册与状态，右版本、文件、反馈、发布；切人需尊重未保存状态 |
| 管理     | 授权名单、时间及版本变化；功能低频放对象菜单         | 同样数据再加报表、版本、规则与导出位置                       |

保留文本、链接、文档或图片规则、草稿同步和附件签名访问。原生或 Web 的提交重复、网络响应丢失、组竞争、评分草稿不可见、旧反馈不改写、锁分数及 0 分、批量退回同意失效、截止和修订窗口须分别举证。
