# 账户与样册逐屏规范

创建与最近更新 2026-11-28 · MicroHub 审计基线 `32150ab4bdd46327f52e42e2431dfaa0b5198b95`

**Proposed**。本页每个界面全部适用 [状态](../INTERACTION_PATTERNS.md)、[响应式](../RESPONSIVE_DESIGN.md)、[双主题](../DESIGN_SYSTEM.md) 和 [无障碍](../ACCESSIBILITY.md)。手机单列设置和头像操作，平板保持适宜阅读宽度，桌面次级信息可并排。两主题展示实际动态颜色，语言及外观支持读屏状态，不遮挡系统返回。

## SCR-21 资料、双语姓名、班级、头像

- 路由与实现 `/profile` · `app/profile.tsx`。目标角色 本人及适用会籍状态。
- 目的与当前问题。资料编辑和头像管理需明确状态回显。
- 目标布局与主操作。本人身份相对位置→可修改字段→头像操作可选；保存与返回固定。
- 组件、次操作和跳转。ProfileForm、ProfilePhoto、Field、Button。
- 状态、权限及恢复。双语名字分别校验、文件上传中、失败撤销、无权头像保持默认。
- 验收。退出及返回后的姓名、头像和班级正确；其他人无权写本人数据。
- 设计依据。GC-03。

## SCR-22 主题、语言、账号及隐私信息

- 路由与实现 `/settings` · `app/settings.tsx`。目标角色 当前授权人。
- 目的与当前问题。设置、More 与桌面菜单重复，账号项路线可更直观。
- 目标布局与主操作。偏好分区，语言与主题、作业通知链接、个人资料、隐私说明和已有安全动作。
- 组件、次操作和跳转。ThemePicker、LanguageToggle、NavigationRow。
- 状态、权限及恢复。持久化失败保持可用且说明；本机及适用存储恢复。
- 验收。EN／ZH 和三种主题切换及时且不清空当前数据；现有权限无变化。
- 设计依据。GC-03、50。

## SCR-23 次级工具与登出

- 路由与实现 `/more` · `app/(tabs)/more.tsx`。目标角色 依会籍及身份。
- 目的与当前问题。与桌面导航、首页账号菜单重复。
- 目标布局与主操作。手机只放次级目的地和账号动作，平板同布局，桌面兼容老 URL，优先从侧栏进入。
- 组件、次操作和跳转。AccountLinks、NavigationRow、ConfirmDialog。
- 状态、权限及恢复。权限变化后链接即时校正；登出失败保留合法重试。
- 验收。访客、停用和活跃的入口区分；主要路径不重复且能退出。
- 设计依据。GC-04、08。

## SCR-24 内部样册

- 路由与实现 `/design-system` · `app/design-system.tsx`。目标角色 开发与验证，合成内容。
- 目的与当前问题。存在组件样例但主题、状态和最窄尺寸不足。
- 目标布局与主操作。按组件和状态分区，显示主题、语言和窄屏预览说明；无生产数据加载。
- 组件、次操作和跳转。当前组件样册、Notice、ThemePicker 后续扩展。
- 状态、权限及恢复。展示 initial、disabled、danger、offline、partial 和长文本。
- 验收。可直接打开，双主题、键盘和无障碍测试选择器稳定。
- 设计依据。MicroHub 工程验证。
