# 长期易用性原则

创建与最近更新 2026-11-28 · MicroHub 审计基线 `32150ab4bdd46327f52e42e2431dfaa0b5198b95`

1. 把登录身份、会籍状态、岗位、组内关系和权限范围表达成不同事实。只有服务端确认后才能展示受保护内容。
2. 按角色显示下一件可执行的事。首页采用真实作业队列、会籍状态及月历，新增统计须有实际行动或可验证含义。
3. 同一目的地用易记名称、稳定位置和固定路由。变宽或回到列表时保留筛选、输入、焦点及上下文。
4. 对象与操作相邻。优先用列表和留白表达分组；表面用于数据群组、提升层级或重要状态。
5. 危险操作先让人看见对象、当前范围和影响；本次前端以服务器返回为准。草稿、服务器回执、评分草稿和已发布值应清楚可分。
6. 双语和导向文案从本地化字典走，状态有文本、无障碍语义和重试操作。保持已确认的业务要求。
7. 引入变更时写需求、证据及验收，变更规范时留 ADR。见 [决策](DESIGN_DECISIONS.md) 与 [验收](UI_UX_ACCEPTANCE_CHECKLIST.md)。
