# 功能逐项映射

创建与最近更新 2026-11-28 · MicroHub 审计基线 `32150ab4bdd46327f52e42e2431dfaa0b5198b95`

ADOPT 为复用设计模式，ADAPT 为调整业务或平台，IMPROVE 为在学会语境中强化，KEEP 为延续既有实现，REJECT 为超出单一学会边界，DEFER 为待业务批准后另立任务。映射的来源是 [Classroom 功能目录](../research/google-classroom/FEATURE_INVENTORY.md)，对应 [真实模块状态](MICROHUB_CURRENT_STATE.md) 与 [逐屏计划](SCREEN_STANDARDS.md)。

教师的任务模式首先映射至大课授权人员、组内研教／负责人及已确认的会长和副会长管理范围，具体权限由既有或已批准服务器合同决定。Classroom 的班级是跨班界面对象。MicroHub 学会是单例，分组仅是受检查的数据范围。应用内没有监护人或校级 IT 管理员对应角色。签到、活动联动、权限任免与长期身份历史是 MicroHub 自身设计课题。
