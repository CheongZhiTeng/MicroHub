| 视口     | 导航                                                          | 内容和交互                                                                                                                                                |
| -------- | ------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 320–639  | 手机底栏 5 项，详见 IA；详情保留 iOS/Android 返回与浏览器返回 | 左右 16，安全区中放固定操作；输入模式下验证主操作不会被遮盖。文件预览全宽或交给已授权查看器。表格转语义行＋详情；批量动作适合满宽面板。网络重试保留输入。 |
| 640–1023 | 默认保留同一底栏，横屏内容足够时验证分类与分栏                | 24 间距；允许两列摘要，主要阅读和写作保持单列。批改或管理主从需实际容器宽度足够，否则单栏。宽度切换不重挂载页面，不清空表单或选择。                       |

| 1440+    | 保持侧栏信息层级                                              | 打开附件预览或日历日期详情利用额外空间，主内容不无条件扩满。                                                                                              |
