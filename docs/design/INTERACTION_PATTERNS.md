# 状态与操作规范

创建与最近更新 2026-11-28 · MicroHub 审计基线 `32150ab4bdd46327f52e42e2431dfaa0b5198b95`

| 状态              | 显示                                                               | 可用命令与恢复                           |
| ----------------- | ------------------------------------------------------------------ | ---------------------------------------- |
| Default           | 标题、必要范围、主动作、内容                                       | 用户明确选择动作                         |
| Loading／Skeleton | 初次无数据用结构占位和读屏加载状态；短命令保留原按钮               | 阻止依赖数据的命令；返回仍可用           |
| Refreshing        | 同身份同范围保留已安全加载内容，局部显示更新                       | 可取消返回、继续只读；授权变化清除数据   |
| Empty             | 区分真实无数据、筛选无匹配、尚未入会及不可访问                     | 适用的清筛选、创建或下一步               |
| Error             | 页内错误、必要字段提示和可行步骤                                   | 重试或返回；保留非敏感已填项             |
| Partial data      | 标明失败区、时间或范围；未知与零分开                               | 仅重试失败区，避免做需要最新数据的动作   |
| Offline           | 用文字说明无法同步与最后可安全展示状态                             | 回网恢复；禁止伪造提交与跨会话缓存       |
| Success           | 可撤销低风险动作只在后端真支持时提供；关键记录显示回执、时间和对象 | 继续下一步、返回、查看服务器结果         |
| Disabled          | 原位灰态和说明；无权限的危险动作按授权隐藏                         | 能修复条件时导航到说明，未授权禁止执行   |
| Pressed／Hover    | 主副层级轻量颜色或边框反馈；触屏不依赖 hover                       | 键盘／触屏均可发现                       |
| Focused           | 明确焦点环及读屏语义；键盘顺序与阅读顺序一致                       | 关闭弹层回触发项                         |
| Selected          | 文字与形状、颜色、选中语义                                         | 保留当前选项，清除时说明范围             |
| Unauthorized      | 无身份，跳到登录时保留安全目标                                     | 登录成功重新授权及验证参数               |
| Permission denied | 泛化不可访问或范围改变，无资源敏感信息                             | 回到当前身份合法页面                     |
| Session expired   | 不重用私有缓存；收到授权失败需重新确认身份                         | 安全登录恢复，认证令牌或私有附件不持久化 |

## 危险操作、上传及保存

- 复用 `useBusy`、`useFormExit`、`HomeworkDraftProvider`、`ConfirmDialog`；根据现有业务保留幂等请求 ID 或 revision。命令在进行中保持单飞，请求超时先读取结果。只有已保存响应才显示提交、签到、评分或审批成功。
- 把草稿与已发布版本分开。支持 Autosave 的模块提供“保存中／已保存时间／未能保存”。没持久化能力的编辑器用未保存提示及显式保存，保留返回路径。
- 高风险管理用对象、范围、影响、原因、确认及可恢复错误。任免预览变旧时重新获取；最后有效管理者限制与并发由服务端执行。邀请码只显示必要的可复制内容，撤销及过期后标记状态，不写入 toast 日志。
- 文件选择前说明允许类型、大小和数量。待上传、上传中、已校验、失败状态独立。失败针对文件重试，保留有效的其它文件；发布前等所有必须文件通过服务器验证。私有链接失败时按现有权限重新签发或明确拒绝。
- 表单错误按字段及摘要建立关联，并可读屏播报；成功及错误使用具体动作结果。可撤销仅在正确服务器合同存在时显示。刷新需说明当前范围，失去权限立即清空受保护视图。
